## 已证明的不变量

1. 最终页面只能从路书当前正式版本创建；
2. 完整性失败返回结构化 issues，不创建分享记录；
3. 数据库不保存明文分享令牌，只保存 SHA-256 哈希；
4. 分享读取始终加载 `final_pages.routebook_version_id`；
5. 当前草稿切换到新版本后，旧分享仍返回原版本；
6. 默认分享策略会移除地点精确地址；
7. 提案预览不会替换工作台持有的正式版本对象。

## 核心路径回放结果

1. 一句话创建路书并进入结构化需求澄清；
2. 补充出发地、日期和交通方式后恢复同一 Workflow Run；
3. 展示推荐理由与交通取舍，接受三个候选；
4. 生成三日行程并切换到服务端返回的版本 2；
5. 展示已验证天气和地图标记；
6. 修改第一天并切换到服务端返回的版本 3；
7. 生成固定版本分享页，确认备注存在且精确地址已隐藏；
8. 移动端工作台和分享页保持完整内容与可操作结构。

确定性回放服务位于 `scripts/serve_phase7_fixture.py`，仅用于本地浏览器验收，不被生产服务导入。

## 阶段八边界

分享撤销、重复最终页治理、全量视觉基线和真实供应商故障演练进入阶段八稳定性与发布门禁；
它们不改变阶段七已经证明的固定版本、隐私和核心用户路径不变量。
