## 2. 高德验证结果

### 2.1 地理编码

输入：`黄鹤楼`，城市：`武汉`。

返回：

- 标准地址：湖北省武汉市武昌区黄鹤楼；
- 坐标：`114.302467,30.544649`；
- 匹配级别：兴趣点；
- 结果数量：1。

### 2.2 POI 搜索

输入：关键词 `黄鹤楼`，区域 `武汉`。

首条结果：

- POI ID：`B001B0I4K0`；
- 名称：黄鹤楼；
- 坐标：`114.302467,30.544649`；
- 类型：风景名胜 / 国家级景点；
- 本次共返回 10 个候选。

实现时不能无条件使用第一条结果。多个候选应结合城市、行政区、地址和距离消歧，关键地点必要时交给用户确认。

### 2.3 驾车路径

武汉市内测试路线返回 2 条候选路线。首条路线：

- 距离：9484 米；
- 预计时长：1224 秒；
- 过路费：0；
- 红绿灯：15 个。

距离与时长应保存为数值并保留本次查询时间；展示层再转换为公里和分钟。

## 3. 和风天气验证结果

### 3.1 接入方式

- Host：使用项目专属 API Host；
- 推荐认证：请求头 `X-QW-Api-Key`；
- Query 参数 `key` 本次也验证成功，但不建议使用，以免密钥进入访问日志和 URL；
- 客户端必须正确处理压缩响应。`curl` 验证时需要 `--compressed`，应用 HTTP 客户端应启用自动解压。

### 3.2 三日天气

返回 3 天数据，包含：

- 预报日期；
- 最低/最高温度；
- 白天/夜间天气现象；
- 风力等级；
- 供应商更新时间。

测试首日返回 27～36℃、晴。

### 3.3 24 小时天气

返回 24 个小时数据，包含：

- 预报时间；
- 温度；
- 天气现象；
- 风力等级；
- 降水量。

### 3.4 灾害预警

接口成功返回武汉地区预警。本次测试包含一条高温黄色预警，并返回发布机构、标题、严重程度、开始时间和结束时间。

预警数组为空是正常业务状态，不应被当作接口失败。

## 4. 实现约束

1. API Key 仅从服务端环境变量读取，不提交到仓库；
2. 日志不得打印完整请求 URL、认证请求头或原始 Key；
3. 和风天气使用 Header 认证，不使用 URL Query 认证；
4. 高德统一按 GCJ-02 保存和展示坐标；
5. 同一天按主要停留地点查询天气，避免每个 POI 重复调用；
6. 同一地点、接口和预报批次需要缓存；
7. 同时判断 HTTP 状态和供应商业务状态码；
8. 超时、限流、认证失败和无结果应转换为统一错误类型；
9. 天气失败不得阻断路线生成；
10. 地图路径失败时保留地点行程，并明确标记路线未验证。
