## 2. 关键业务门禁

- 无法唯一解析的“这个地点”等引用不会进入预览或正式提交；
- 预览与当前正式版本隔离，重要修改确认前不更新 `current_version_id`；
- 删除或替换必去地点必须确认，不能通过普通编辑直接提交；
- 总天数变更的影响范围包含新增或删除的日期，避免漏过哈希检查；
- 受影响日期重新查询路径和天气，未受影响日期复制原始对象与事实；
- 提交前比较未受影响日期的规范化哈希，变化时返回 `UNEXPECTED_SCOPE_CHANGE`；
- 提案确认时重新检查 `base_version_id`，陈旧提案返回 `VERSION_CONFLICT`；
- operation ID 同内容可安全重试，不同内容或跨路书复用返回幂等冲突；
- 撤销复制当前版本的父版本快照，创建递增 `undo` 版本，不删除任何历史。
